# PRD — iambox

> 기준일: 2026-10-01. **구현**은 현재 코드, **예정**은 기존 PRD의 제품 요구사항, **TBD**는 미확정 사항을 뜻한다. 코드와 다르면 실제 코드를 확인하고 문서를 갱신한다.

## 프로젝트 개요

- 프로젝트명: 앱 이름 `iambox`, 저장소 `iambox_app`.
- 목적: 학습용 MVP에서 시작하여 실제 셀프스토리지 서비스로 확장한다.
- 서비스 설명: 주변 지점을 찾고 보관 공간을 선택한 뒤 결제하고 QR로 출입하는 모바일 서비스 **예정**.
- 대상 사용자: 보관 공간을 찾고 이용하려는 개인 사용자로 해석한다. 세부 고객군은 **TBD**.
- 대상 제품 플랫폼: iOS / Android. Expo 설정의 태블릿 지원·웹 favicon만으로 별도 태블릿 UX나 웹 서비스 제공을 확정하지 않는다. Next.js 웹은 같은 모노레포의 공통 코드 확인용 기본 화면까지 구성했으며 실제 웹 제품 흐름은 후속 범위다.

## 현재 구현 상태

- pnpm 워크스페이스에 `mobile/`, `api/`가 있다.
- 마이페이지는 예시 프로필, 나의 박스·이용 내역·결제 내역·문의하기 바로가기, 이용 관리(알림설정·택배예약·사전예약·케어서비스), 고객지원(공지사항·FAQ·문의하기), 로그아웃 버튼과 약관·개인정보처리방침 링크를 표시한다. 나의 박스는 기존 출입QR의 내 공간 화면으로 이동하고 이용 내역은 기존 mock 안내, 나머지 메뉴는 예시·준비 안내 모달을 연다. 약관과 개인정보처리방침은 모달 표시만 구현했으며 정식 본문·인증·로그아웃·알림 설정 변경·예약 접수·결제 조회는 미구현이다. 이용후기와 이용 중인 공간 요약 카드는 표시하지 않는다.
- 앱은 홈 · 지점찾기 · 출입QR · 택배 · 마이 하단 탭을 표시한다. 홈에는 소개, 물품 보관 카드와 오른쪽 택배요청·사전방문 카드, 원형 바로가기 4개(창업문의·지점 찾기·AI 견적·공지사항), 이벤트 배너·후기 예시를 표시한다. 홈의 지점 찾기는 기존 탭으로 이동하며 나머지 서비스는 준비 안내를 연다.
- 출입QR 탭에는 이용 중인 보관 공간, 기간, 남은 일수, 방문 안내와 문의 UI를 표시한다. 성수점 A-024의 mock 데이터를 사용하며 버튼은 예시 이용 내역·안내 모달을 연다. 실제 출입 QR 발급·인증, 지도 길찾기, 문의 접수는 미구현이다.
- `출입 QR 열기`로 QR 안내창을 열면 앱이 활성 상태인 동안 화면을 최대 밝기로 설정한다. 닫기·뒤로가기·화면 이탈·앱 전환 시 이전 밝기로 복원하고 QR을 유지한 채 돌아오면 다시 높인다. Android는 기존 시스템 밝기 사용 상태도 복원한다. 밝기 기능은 네이티브 모듈을 포함한 앱에서 동작하며 실기기 확인은 대기 중이다. 다른 안내 모달의 밝기는 변경하지 않는다.
- 지점찾기 탭은 네이버 지도에 강남점·서초점·성수점의 mock 좌표와 가격을 표시한다. 사용자 제공 로고의 왼쪽 심볼·지점명·시작 가격을 담은 3px 보라색 말풍선 마커를 누르면 해당 지점의 예시 주소·요금을 보여주는 상세 화면으로 이동한다. 화면 이름에는 mock 접두사를 넣지 않고 `mockLocations`와 ID에서 구분하며, 화면에는 예시 데이터 안내를 표시한다. 상세에서 지도 복귀 시 카메라를 유지한다. 지도 하단에는 접힘·중간·펼침 높이를 가진 공통 바텀 시트와 스크롤 가능한 예시 지점 목록을 표시한다. 목록은 이미지·이름·위치 아이콘이 있는 주소·최저가를 표시하며, 선택한 행과 지도 마커를 같은 ID로 강조한다. 더보기 없이 지점 행 전체를 누르면 기존 상세를 연다. 목록은 주소 → 이용 가능한 사이즈 → 최저가 순서다. 화면 최상단 지도 바로 위에 고정 배치한 지역·지점명 검색과 사이즈 필터를 지도·목록에 함께 적용한다. 검색 영역은 바텀 시트 밖에 있어 시트를 펼쳐도 상단에 유지된다. 사이즈 필터는 모달에서 임시 선택한 뒤 적용하고 활성 칩으로 삭제한다. 손잡이와 버튼으로 높이를 바꾸며 상세 복귀 시 시트 높이도 유지한다. Expo Go는 준비 안내를 표시한다. 행정구역 개수·특가·지도/목록 모드 전환·목록 선택 시 카메라 이동·실제 지점 API는 후속 단계다.
- Next.js `web/`은 기본 실행 구조를 구성했다. 공통 UI 확인용 예시 내용은 사용자 요청으로 제거해 현재 홈 화면은 비어 있다. 공유 패키지 설정은 유지하며 API·로그인·결제·지도는 연결하지 않았다. [통합 검증 기록](superpowers/plans/2026-10-02-monorepo-stage6.md)을 따른다.
- 서버는 `GET /`에 `Hello World!` 문자열을 반환한다.
- Prisma의 PostgreSQL 연결과 연결 확인 CLI가 있다. 스키마에 모델은 없다.
- 앱–API 연결과 실제 인증·지점 조회·공간 계약·결제·QR 발급 기능은 미구현이다. 홈과 출입QR의 UI는 정적 예시 데이터로 표시한다.

### 지점찾기 상세 요구사항 — 기본 지도와 mock 가격 마커 (2026-10-01)

- 사용자 설명 기준 현재 약 300개 지점이며 향후 증가를 고려한다. 실제 지점 데이터는 아직 저장소에 연결되지 않았다.
- 지도를 축소하면 강남구·서초구처럼 행정구역별 정확한 지점 개수를 표시하고, 확대하면 개별 지점의 가격·특가 할인 문구·특징을 표시한다. 거리 기반 자동 군집으로 지역 개수를 대신하지 않는다.
- 지도와 지점 목록을 전환할 수 있으며 선택한 지점을 서로 연결한다.
- 군집별 최저가 집계는 이번 범위에 포함하지 않는다.
- 우선 예시 데이터로 모바일 화면을 구현하고, 실제 지점 API·DB 연동은 후속 범위로 둔다.
- 기존 기본 지도 → 행정구역 개수 → 가격·특가 마커 → 목록 연동 → 안정성·규모 검증 계획은 유지한다. 2026-10-01 사용자 요청에 따라 소수의 mock 지점에 단순 가격 마커·상세 이동을 먼저 구현했다. 2026-10-01 바텀 시트에 예시 목록·선택 강조·상세 이동을 추가했다. 행정구역 집계·특가·실제 특징 데이터·지도/목록 모드 전환·목록 선택 시 카메라 이동·300개 규모 검증을 완료한 것으로 간주하지 않는다.
- iOS·Android 지도 제공자는 네이버로 통일한다. 집계 기준·화면 동작·검증 기준은 [Architecture의 승인 설계와 진행 기록](ARCHITECTURE.md#지점찾기-지도-설계와-단계별-진행)을 따른다. 클러스터 패키지는 도입을 보류했으며 현재 네이버 지도 라이브러리·네이티브 인증 설정과 mock 가격 마커·상세까지 적용했다. 이번 가격 마커는 별도 요청 범위이며, 이후 단계는 해당 범위의 사용자 요청과 검토에 따라 진행한다.

## 핵심 사용자 흐름

현재: 앱 실행 → 홈 블록 화면 → 하단 탭 선택 → 출입QR은 mock 내 공간 화면, 지점찾기는 mock 가격 지도와 지점 상세, 마이는 예시 프로필·메뉴 화면, 택배는 임시 화면 표시. 마이의 나의 박스는 출입QR 탭으로 이동한다. 출입QR·마이의 버튼으로 이용 내역과 안내 모달을 열고 닫을 수 있다. 지점 마커를 누르면 예시 상세 화면으로 이동하고 뒤로가기로 지도로 복귀한다.

다음은 **예정** 흐름이다. 로그인 필수 시점과 예외 흐름은 TBD다.

```text
앱 실행 → 회원가입/로그인 → 홈 → 지도 또는 지점 목록
→ 지점 선택 → 상세 확인 → 보관 공간 선택 → 기본 결제 → 이용 시작
앱 → QR 화면 → QR 인증 → 출입
홈 → 마이페이지 → 사용자 정보 확인
```

## 화면 목록

| 화면 | 역할 | 상태 |
| --- | --- | --- |
| 하단 탭 / 임시 화면 | 홈 · 지점찾기 · 출입QR · 택배 · 마이 이동 (`App.tsx`) | 구현, 업무 기능 없음 |
| 회원가입 / 로그인 | 계정 생성·인증 | 예정 |
| 홈 | 소개, 큰 물품 보관 + 오른쪽 서비스 2개, 원형 바로가기 4개, 이벤트·후기 예시 | UI·지점찾기 탭 이동·준비 안내 구현, 실제 서비스·데이터 연동 예정 |
| 지도 | 지점 위치·마커 표시 | 로고·지점명·예시 가격 커스텀 마커 구현 |
| 지점 목록 | 지점 탐색 | 바텀 시트 예시 목록·선택 강조·상세 이동 구현, 실제 데이터·예약 연동 예정 |
| 지점 상세 | 지점명·주소·요금 확인 | mock 상세·지도 복귀 구현, 실제 시설·조회는 예정 |
| 공간 선택 | 이용할 보관 공간 선택 | 예정 |
| 결제 | 기본 결제 진행·결과 확인 | 예정 |
| 출입QR / 내 공간 | 이용 중인 보관함·기간 확인, 방문 안내·문의 | mock UI와 안내 모달 구현, 실제 QR 발급·출입 인증 예정 |
| 마이페이지 | 예시 프로필, 내 공간 이동, 이용 관리·고객지원, 약관 링크 | UI·탭 이동·안내 모달 구현, 실제 서비스·계정·정식 약관 연결 예정 |

하단 탭은 홈 · 지점찾기 · 출입QR · 택배 · 마이 순서다. 지점찾기의 지도·목록과 지점 상세에서도 하단 탭을 계속 표시하며 다른 탭으로 이동할 수 있다. 지도·목록 화면 최상단에는 검색창과 필터만 표시한다. 지점 상세의 상단 뒤로가기는 지도·목록으로 돌아간다. Android 뒤로가기는 지점 상세 닫기 → 펼친 목록 접기 → 진입 전 화면 복귀 순서로 처리한다. 현재 App.tsx의 로컬 상태로 화면을 전환하며, 라우터는 없으며 지점 상세는 `LocationsContent`의 로컬 선택 상태로 표시한다. 택배의 상세 기능은 TBD다.

## 개발 원칙

- 작은 MVP부터 시작한다.
- 요청된 단계만 구현하고 다음 단계 기능을 미리 구현하지 않는다.
- 실제 필요가 생겼을 때 구조를 확장한다.
- 기존 패턴을 우선하며 사용하지 않는 레이어와 과도한 추상화를 만들지 않는다.
