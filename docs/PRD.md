# PRD — iambox

> 기준일: 2026-09-29. **구현**은 현재 코드, **예정**은 기존 PRD의 제품 요구사항, **TBD**는 미확정 사항을 뜻한다. 코드와 다르면 실제 코드를 확인하고 문서를 갱신한다.

## 프로젝트 개요

- 프로젝트명: 앱 이름 `iambox`, 저장소 `iambox_app`.
- 목적: 학습용 MVP에서 시작하여 실제 셀프스토리지 서비스로 확장한다.
- 서비스 설명: 주변 지점을 찾고 보관 공간을 선택한 뒤 결제하고 QR로 출입하는 모바일 서비스 **예정**.
- 대상 사용자: 보관 공간을 찾고 이용하려는 개인 사용자로 해석한다. 세부 고객군은 **TBD**.
- 대상 플랫폼: iOS / Android. Expo 설정의 태블릿 지원·웹 favicon만으로 별도 태블릿 UX나 웹 서비스 제공을 확정하지 않는다.

## 현재 구현 상태

- pnpm 워크스페이스에 `mobile/`, `api/`가 있다.
- 앱은 홈 · 지점찾기 · 출입QR · 이삿짐 · 마이 하단 탭을 표시한다. 탭 선택과 임시 화면 전환만 구현되어 있다.
- 서버는 `GET /`에 `Hello World!` 문자열을 반환한다.
- Prisma의 PostgreSQL 연결과 연결 확인 CLI가 있다. 스키마에 모델은 없다.
- 앱–API 연결, 업무 화면, 인증, 지점·공간·결제·QR 기능은 모두 미구현이다.

## 기술 스택

아래 버전은 package.json 선언 기준이다.

| 영역 | 현재 기술 |
| --- | --- |
| 모바일 | React Native 0.86.3, Expo ~57.0.25, React 19.2.3, expo-status-bar ~57.0.1 |
| 백엔드 | NestJS ^12.1.1, platform-express, reflect-metadata, RxJS |

| 데이터베이스 | PostgreSQL. 기존 서버 README는 로컬 17.11 사용을 기록함; 이번 문서 작업에서 서버 버전·가동 상태는 재검증하지 않음 |
| 공통 | TypeScript ~6.0.3, pnpm 12.6.0, dotenv(서버) |

Node.js 22.23.3은 루트 README에 기록된 구성 환경이며 package.json에 engines로 강제하지 않는다. 라우터, 전역 상태 관리, 지도·QR·결제 SDK는 아직 없다.

## 핵심 사용자 흐름

현재: 앱 실행 → 홈 임시 화면 → 하단 탭 선택 → 해당 메뉴 임시 화면 표시.

다음은 **예정** 흐름이다. 로그인 필수 시점과 예외 흐름은 TBD다.

```text
앱 실행 → 회원가입/로그인 → 홈 → 지도 또는 지점 목록
→ 지점 선택 → 상세 확인 → 보관 공간 선택 → 기본 결제 → 이용 시작
앱 → QR 화면 → QR 인증 → 출입
홈 → 마이페이지 → 사용자 정보 확인
```

## 개발 원칙

- 작은 MVP부터 시작한다.
- 요청된 단계만 구현하고 다음 단계 기능을 미리 구현하지 않는다.
- 실제 필요가 생겼을 때 구조를 확장한다.
- 기존 패턴을 우선하며 사용하지 않는 레이어와 과도한 추상화를 만들지 않는다.
- 예정 기능을 현재 동작으로 설명하지 않는다. 구현 시 이 문서의 상태도 바꾼다.
